# Django Customer Management API

A Django-based Customer Management API built for learning backend development with Django, MySQL, and REST APIs.

## Current Features

- Django project and app setup
- MySQL database integration
- Customer model
- Django Admin
- Get all customers
- Get customer by ID
- Create customer using POST API

## Technologies

- Python
- Django
- MySQL
- REST API
- Postman
- Git & GitHub
